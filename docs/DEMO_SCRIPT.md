# Homecoming OS demo script (target: 2 minutes 30 seconds)

**Important:** show the actual app running. Do not use a generated video in place of product footage. Keep the demo under three minutes, upload publicly to YouTube or Vimeo, and avoid copyrighted music or footage.

## 0:00–0:15 — The problem
“Managing a home means checking several things separately. Homecoming OS turns one arrival request into a transparent, multi-step workflow.”

## 0:15–0:35 — Show the dashboard
Point to the package status, device states, and home activity. Say: “This is a simulated environment. The assistant uses visible fixture data rather than inventing a delivery confirmation.”

## 0:35–1:05 — Trigger the workflow
Click **Run arrival scenario**. Show the natural-language request, summary, and evidence checked. Highlight that the package is still marked “In transit”.

## 1:05–1:40 — Show action orchestration
Walk through the ordered steps. Run the “Prepare evening routine” step. For the roommate update, show the approval gate and click **Approve & execute**. Explain that the action updates simulated app state only; it does not send a real message.

## 1:40–2:05 — Show memory/preferences
Open Preferences. Toggle “Ask before messaging” or change the lighting time. Explain that preferences are saved by the API to a JSON file. On a free/ephemeral host they may reset after a restart unless persistent storage is configured.

## 2:05–2:25 — Close
“Homecoming OS combines contextual state, evidence-backed decisions, multi-step actions, approval gates, and persistent preferences in one simulated Alexa+-style experience.”

## Recording checklist
- Use a clean browser window at a readable zoom.
- Make sure both frontend and backend are running before recording.
- Keep the mouse movement deliberate; do not leave long pauses.
- Record narration in English.
- End with the app functioning and the repo URL visible or listed in the video description.
